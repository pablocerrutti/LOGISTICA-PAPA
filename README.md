# LOGISTICA-PAPA — Operativo Florida

Aplicación web para marcar zonas y recorridos en el mapa de Florida, Uruguay.

## Publicar
1. Descomprimí el ZIP.
2. Subí `index.html` y `README.md` a la raíz del repositorio `pablocerrutti/LOGISTICA-PAPA`, rama `main`.
3. En GitHub: **Settings → Pages → Deploy from a branch → main → /(root) → Save**.
4. Esperá la publicación.

Requiere conexión a Internet para Leaflet y los mapas de OpenStreetMap. Las zonas se guardan en el navegador local; usá Exportar JSON para hacer copias de seguridad o Importar JSON para restaurarlas.
